快速學習更新包

這是待上傳的網站修正版，尚未修改正式網站。

使用方式
1. 將本包的 js 與 css 資料夾上傳到 GitHub English-Vocabulary 專案的同名資料夾，覆蓋 app.js、store.js、style.css，並新增 quick-core.js、quick-quiz.js。
2. 等待 GitHub Pages 更新，在原本使用的瀏覽器按 Ctrl+F5 重新整理。
3. 選原學習者，按「今日學習」。單字不需重新匯入，課程不需重新發布，既有學習紀錄保留。

本次流程
- 每天最多 15 個新字在同一頁全部展開，包含中文、詞性、例句、翻譯、片語與搭配例句，可直接捲動閱讀。
- 例句中的目標字為加粗、放大的紅字；保留朗讀與收藏。
- 閱讀完按一次「開始四選一」，沿用原例句挖空，提供 1 個標準答案及 3 個拼字相近的真實單字。
- 答對立即下一題，不必再點熟悉度或下一題。答錯立即加入錯題練習、顯示正解並重練，重練答對才計入完成。
- 同日到期複習接在新字後面，使用相同測驗方式。完成全部題目與錯題後即完成該日任務。
- 先儲存本機，再背景同步；中斷後可在相同瀏覽器繼續。右上角顯示同步狀態。
- 20 分鐘是節奏目標，沒有倒數或強制跳過；到期複習較多時時間可能增加。

題庫內容
如果原例句沒有目標字或明列的 acceptedAnswers 詞形，會明確提示暫用中文四選一；不會捏造例句。若需題題都有例句，可在管理頁補齊例句後發布新版本。既有固定課程不會被悄悄改写。
干擾選項以拼字距離排序並略優先相同詞性，中文提示限定本題詞義；仍需人工審核語義合理性。

本次不需額外修改 Firebase 規則。若之前的「第 1 天啟用」尚未完成，仍需先依上一版說明啟用課程。
