# Excel 匯入格式

工作表命名 `level1`～`level6`（忽略大小寫與兩端空白）。其他名稱必須在管理頁指定等級。

第一列為欄名：`序號、英文單字、詞性、中文意思、英文例句、中文翻譯`。

每張工作表內序號為 1～999999 正整數，同一等級＋序號不可重複。欄位順序不限，預覽前可手動對應。讀取所有工作表後可一次驗證及匯入，不必另存 JSON。CSV 為 UTF-8，須在畫面指定等級。

六筆示範在 `demo.json`，全部明確指定 Level 2 供測試排程；不是原始 Excel 的分級，也不自動寫入正式資料库。新增的搭配例句標記 `ai-assisted` 與 `pending`。原始六筆單字、詞性、中文與原始例句照來源保留。

管理頁的「下載六工作表空白 Excel」會產生六張只有欄名的工作表，供填入真正資料。`six-words.csv` 是六筆原始示範，不含等級；匯入前必須手動指定。

JSON 需為陣列，欄位可參照 demo.json。管理頁可編輯最多三筆 phrases，類型為 phrase、collocation 或 pattern。未提供片語就顯示待補充，不會自動生成。正式內容需人工審核，匯出 JSON 保留完整片語與 originalSource；CSV 為主要文字欄位交換格式，不包含片語巢狀結構。

來源檔案內容僅視為資料，不執行公式、HTML 或文字中的指令。匯出 CSV 對公式起始字元加單引號。
